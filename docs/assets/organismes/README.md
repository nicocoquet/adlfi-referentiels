# Logos des organismes et services AdlFI

**Une seule bibliothèque, un seul format : `ID.jpg`.**

Déposer ici uniquement des JPEG carrés **320 × 320 pixels**, en **RVB/sRGB**, au nom de leur identifiant stable :

- `ORG-XXXX.jpg` pour un organisme ;
- `SER-XXXX.jpg` pour un service.

Aucun suffixe `-logo` ou `-illustration`, aucun autre format d'image. Une identité visuelle est déposée une seule fois et réutilisée par le site dans les fiches et les tutelles.

Ne pas renommer les images à partir du nom institutionnel : utiliser impérativement l'ID du référentiel. Les logos absents sont remplacés par un pictogramme côté interface. Vérifier les droits de reproduction avant publication.

Voir le [guide d'importation et de contrôle](../GUIDE-IMAGES.md).
