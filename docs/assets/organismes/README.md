# Médias des autorités institutionnelles

Bibliothèque **unique** pour les organismes et les services, qu’ils apparaissent comme entités consultées ou comme tutelles d’autres entités.

Déposer ici les fichiers nommés `ORG-XXXX-logo.svg`, `ORG-XXXX-illustration.webp`, `SER-XXXX-logo.png`, etc., dans les formats .jpg, .jpeg, .png, .webp ou .svg.

Un logo d’une autorité n’est enregistré **qu’une fois**. Il peut figurer dans sa propre fiche et dans les bandeaux de tutelles des laboratoires.

Lire [le guide complet](../GUIDE-IMAGES.md) avant tout ajout. Seuls les médias dont les droits d’utilisation sont établis peuvent être publiés.
