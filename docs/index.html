Référentiels AdlFI

Un espace de consultation des autorités, organismes, lieux et vocabulaires documentaires employés dans l’édition scientifique d’AdlFI. Chaque référentiel possède ses propres règles de validation, de datation et d’identification.

Lieux

Ce module accueillera les correspondances validées entre autorités géographiques Pactols et communes du Code officiel géographique (COG), avec les millésimes et sources. Aucune commune n’est géocodée ici par simple rapprochement de libellés.

Natures d’opération

Ce module présentera les natures d’opérations employées dans AdlFI et les correspondances avec les codes des anciens bilans scientifiques régionaux (BSR). Il distinguera les libellés éditoriaux, les codes sources et les concepts Pactols lorsque les alignements sont vérifiés.
