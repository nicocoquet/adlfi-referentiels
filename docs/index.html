Référentiels AdlFIVocabulaires contrôlés pour l’archéologie

À venir

Atlas

Ce module présentera un atlas documentaire croisant les opérations archéologiques publiées dans AdlFI et les articles des revues Gallia. Il permettra d’explorer ces corpus dans leurs dimensions géographiques et chronologiques, à partir de données localisées, indexées et contrôlées.

À venir

Lieux

Ce module présentera les correspondances validées entre autorités géographiques Pactols et communes du Code officiel géographique (COG), avec les millésimes et sources. Aucune commune n’est géocodée ici par simple rapprochement de libellés.

À venir

Personnes

Ce module présentera un référentiel de personnes (responsables d’opération, auteurs et autres contributeurs) mentionnées dans les publications d’AdlFI. Il distinguera les formes attestées, les variantes et les identifiants pérennes.

Disponible

Organismes

Ce module présente le référentiel des organismes et services mentionnés dans les publications d’AdlFI. Il permet de rechercher les structures, d’explorer leurs relations institutionnelles et de consulter leurs identifiants, leurs implantations et leur historique.

À venir

Natures d’opération

Ce module présentera les natures d’opérations employées dans AdlFI et les correspondances avec les codes des anciens bilans scientifiques régionaux (BSR). Il distinguera les libellés éditoriaux, les codes sources et les concepts Pactols lorsque les alignements sont vérifiés.
