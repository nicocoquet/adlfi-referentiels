## Entrées et méthode

Le fichier `lot_editorial_prioritaire_001.csv` communiqué le 13 novembre 2026
contient 100 ARK Pactols distincts (un lieu par ligne) avec le code retenu
par concordance du libellé et du département Pactols avec le fichier
`v_commune_depuis_1943.csv` (COG 2026).

La revue éditoriale est conservée dans
`docs/lieux/recette/lot-001-prearbitrages.csv`. Ses 100 lignes gardent le
statut **NON VALIDÉ — proposition**. Le fichier initial et ses candidats
multiples ne doivent jamais être écrasés par la grille de décision.

Les 100 pré-alignements se répartissent en 47 candidatures lexicalement
uniques dans le COG historique et 53 cas de plusieurs codes homonymes ou
administrativement successifs. Le filtre départemental laisse un seul
code candidat dans les 100 cas. **Cela ne démontre ni identité historique
ni équivalence SKOS ni présence d'une géométrie valide à la date de l'opération.**

### Deux cas de structure historique

- **Allaines-Mervilliers, `28002`** : identité communale `COM`
  jusqu'au 1er janvier 2019. La notice AdlFI observée porte sur
  1998. Selon l'Insee, l'ancienne commune devient une commune déléguée
  de Janville-en-Beauce (`28199`) en 2019. Conserver l'entité historique,
  son code et ses dates, puis décrire explicitement le rattachement.
  Ne pas affecter à Allaines-Mervilliers le contour 2026 de la commune nouvelle.
- **Aigondigné, `79185`** : commune nouvelle créée le 1er janvier
  2019. Le même code a antérieurement identifié Mougon puis
  Mougon-Thorigné. Conserver des **épisodes d'identité administrative**
  distincts et vérifier les événements 2017 et 2019 (notamment les créations de communes nouvelles, **MOD = 32**) avant le raccordement
  historique et géométrique.

### Anomalie d'indexation possible

- **Brain, ARK `26678/pcrtXSoREPOwqU`, COG candidat `21100`** :
  chaîne géographique Pactols située sous la Côte-d'Or, mais unique
  attestation retrouvée dans `AdlFI_PdL_2008.xml`, notice
  « Pays de Retz ». Inspecter le XML et le contexte géographique de
  l'occurrence avant de valider l'alignement.
- **Antony et Aulnay-sous-Bois** : les fichiers témoins sont situés
  dans des répertoires marqués `A-VERIFIER`. Cette mention est une
  alerte de provenance, non une preuve d'invalidité du lieu.

### Contexte des titres

Pour 25 ARK sur 100, aucun titre de notice extrait ne contient leur
libellé normalisé. **Ce n'est pas une anomalie par défaut** : le contrat
AdlFI reconnaît l'indexation géographique dans tout le corps de la notice,
pas seulement dans le titre. Une notice indexée suffit à attester le
concept dans le corpus.

## Contrat de raccordement à maintenir

1. L'**ARK Pactols** désigne l'autorité documentaire : préserver
   ses chaînes hiérarchiques, variantes et attestations.
2. La **tranche d'identité administrative** est qualifiée par
   (`typecom`, `code_insee`, périodes, événements), sans
   supposer qu'un code invariant équivaut à un territoire invariant.
3. Un **objet géométrique** est qualifié par producteur, licence,
   millésime, niveau de généralisation et empreinte. Le contour
   2026 ne devient pas une limite historique par rétroprojection.
4. Une nouvelle correspondance doit être **validée éditorialement**
   avant sa publication dans `docs/data/lieux.json`.
5. La table des **événements communaux** est obligatoire pour
   documenter les transitions de codes ou les fusions / communes nouvelles ;
   les seuls couples code–libellé ne suffisent pas.

## Exécution reproductible de l'audit des événements (sans publication)

Le fichier officiel s'appelle **`v_mvt_commune_2026.csv`** (avec un
soulignement après `mvt`). Le script ne modifie aucune entrée.

```bash
mkdir -p "$HOME/Desktop/AdlFI-sources-COG-2026"
curl -fL --retry 3 \
  "https://www.insee.fr/fr/statistiques/fichier/8740222/v_mvt_commune_2026.csv" \
  -o "$HOME/Desktop/AdlFI-sources-COG-2026/v_mvt_commune_2026.csv"

python3 scripts/auditer_evenements_cog_lot.py \
  --lot "$HOME/Desktop/AdlFI-lieux-qualification-recette/lot_editorial_prioritaire_001.csv" \
  --evenements "$HOME/Desktop/AdlFI-sources-COG-2026/v_mvt_commune_2026.csv" \
  --sortie "$HOME/Desktop/AdlFI-lieux-evenements-recette"
```

Sorties : `transitions_code_a_verifier.csv`,
`evenements_communaux_particuliers.csv` et
`rapport_evenements_lot001.json`. Les résultats restent
**non validants** et documentent les numéros de modifications (`MOD`).
Les correspondances Pactols–COG restent à arbitrer séparément.
