Natures d’opération

Module en préparation

Classifications et correspondances

Ce module présentera les natures d’opérations employées dans AdlFI et les correspondances avec les codes des anciens BSR. Il devra distinguer les libellés éditoriaux, les codes sources et les concepts Pactols lorsque les alignements sont vérifiés.

La nomenclature existe dans les processus de rétroconversion et d’indexation ; son export public sera formalisé séparément.
