## Preuve de parité différentielle avec l'exporteur officiel

L'exporteur officiel **n'a pas été réexécuté directement** sur le classeur privé 1.56 dans cette séance. En revanche, sa sortie sur le périmètre impacté est entièrement déterminée par l'état 1.55 déjà recetté et par les 45 modifications vérifiées du maître.

1. **Code de transformation identique entre 1.55 et 1.56** : blobs GitHub inchangés pour `scripts/export_organismes.py` (`f43152e4efc39e7509fb26398104f1c5a8b9aa54`), `sector_inheritance.py` (`4776028310d553cb6e99f0fc7c416afbb4e7931f`) et `level_inheritance.py` (`fbfff250b063aabfda2ad4e9f5959dc130d5d174`).
2. **Entrées XLSX inchangées sauf les deux feuilles AFF/COR**, démontré par comparaison OOXML : 45 cellules modifiées, réparties entre `Affiliations_sources` colonnes F (10) et G (12), `Correspondances_affiliations` colonnes D (1), E (20), F (1), G (1). Tous les identifiants AFF/COR, organismes/services cibles et nombres d'occurrences restent identiques.
3. **Champs effectivement lus par l'exporteur officiel** : pour ces deux feuilles, seuls `Affiliations_sources.affiliation_source_id`, `Affiliations_sources.occurrences`, `Correspondances_affiliations.affiliation_source_id`, `organisme_id`, `service_id`, `statut_validation` influencent les fiches. Les modifications de `statut_correspondance` (statut global AFF), `type_correspondance`, `source_url` et `commentaire` sont volontairement sans effet dans le JSON public. Les **20 validations COR** modifient uniquement `usage.affiliations_validated` de huit fiches, puisque l'exporteur dédoublonne par couple AFF–autorité.
4. **Résultat indépendant sur le maître privé** : comparaison OOXML et recomptage de toutes les COR, soit huit compteurs recalculés : CNRS 22 ; Inrap 18 ; Université Paris Nanterre 1 ; Rouen Normandie 1 ; PréTech 10 ; MSH Mondes 1 ; GAVS 6 ; SAD24 1. 24/24 contrôles réussis.
5. **Publication publique** : seules ces huit valeurs et les deux champs de provenance (nom/empreinte) diffèrent du JSON 1.55. Le test Node reconstruisant intégralement le JSON 1.55 produit l'empreinte FNV64 UTF-16 `78878d86e3a9e382`, conforme à la version précédente. Les médias, les 934 autorités, les 600 relations, les 682 fiches visibles et les classifications sont inchangés.
6. Le test sur l'exporteur officiel `scripts/recette_parite_organismes_156.py` reste disponible **en contrôle complémentaire direct** sur le poste éditorial, avec le maître privé. Il ne faut pas confondre cette preuve d'équivalence différentielle avec une exécution directe de ce script.

**Conclusion** : sur le périmètre de publication modifié par A05d, la sortie de l'exporteur officiel est déductible sans ambiguïté et correspond aux modifications publiées. Les nouveaux tests Python/Node et Chromium réussis vérifient les invariants indépendamment des données privées.
